## 1. 原料基本资料（主磅/微量）

### 查询

**请求方法:** `HTTP GET`

**请求地址示例:**

```
http://192.168.99.202:8000/mws/api?option=getParts
  &plant=PLANT&machineId=MACHINEID
  &partNo=PARTNO&partName=PARTNAME&partClass=PARTCLASS
  &unitBarcodeWeight=UNITBARCODEWEIGHT
```

**参数说明:**

| No | 参数 | 数据类型 | 说明 |
|----|------|----------|------|
| 1 | option | nvarchar(50) | API 标识，此操作固定为 `getParts` |
| 2 | plant | nvarchar(50) | 厂别，可为空 |
| 3 | machineId | int | 设备编号，不可为空 |
| 4 | partNo | nvarchar(50) | 原料编号，可为空 |
| 5 | partName | nvarchar(100) | 原料名称，可为空 |
| 6 | partClass | varchar(2) | 原料类别，可为空（`5` = 原料，`2` = 胶料） |
| 7 | unitBarcodeWeight | decimal(10,3) | 单位条码重量(kg)，可为空 |

**返回结果格式:** JSON

查询成功：

```json
{
  "success": 1,
  "rtnmsg": "ok",
  "rtndata": [
    {
      "partNo": "M001",
      "partName": "1号原料",
      "partClass": "5",
      "unitBarcodeWeight": 0.00
    },
    {
      "partNo": "M002",
      "partName": "2号原料",
      "partClass": "5",
      "unitBarcodeWeight": 0.00
    }
  ]
}
```

查询失败：

```json
{
  "success": 0,
  "rtnmsg": "Invalid parameter:option",
  "rtndata": []
}
```

## 2. 原料与料桶（主磅/微量）

### 查询

**请求方法:** `HTTP GET`

**请求地址示例:**

```
http://192.168.99.202:8000/mws/api?option=getMaterialInBuckets
  &plant=PLANT&machineId=MACHINEID
  &bucketNo=BUCKETNO&materialNo=MATERIALNO
```

**参数说明:**

| No | 参数 | 数据类型 | 说明 |
|----|------|----------|------|
| 1 | option | nvarchar(50) | API 标识，此操作固定为 `getMaterialInBuckets` |
| 2 | plant | nvarchar(50) | 厂别，可为空 |
| 3 | machineId | int | 设备编号，不可为空 |
| 4 | bucketNo | nvarchar(20) | 料桶编号，可为空 |
| 5 | materialNo | nvarchar(50) | 原料名称，可为空 |

**返回结果格式:** JSON

查询成功：

```json
{
  "success": 1,
  "rtnmsg": "ok",
  "rtndata": [
    { "bucketNo": "NO.01", "materialNo": "M001" },
    { "bucketNo": "NO.02", "materialNo": "M002" }
  ]
}
```

查询失败：

```json
{
  "success": 0,
  "rtnmsg": "Invalid parameter:option",
  "rtndata": []
}
```

### 写入

**写入方法:** `HTTP POST`

**数据格式:** JSON

**参数说明:**

| No | 参数 | 数据类型 | 说明 |
|----|------|----------|------|
| 1 | option | nvarchar(50) | API 标识，此操作固定为 `updateMaterialInBuckets` |
| 2 | plant | nvarchar(50) | 厂别，可为空 |
| 3 | machineId | int | 设备编号，不可为空 |
| 4 | bucketNo | nvarchar(20) | 料桶编号，不可为空 |
| 5 | materialNo | nvarchar(50) | 原料编号，不可为空 |

**写入数据示例:**

```json
{
  "option": "updateMaterialInBuckets",
  "plant": "",
  "machineId": 1,
  "bucketNo": "NO.01",
  "materialNo": "M001"
}
```

## 5. 密炼工艺

### 写入

**写入方法:** `HTTP POST`

**数据格式:** JSON

**参数说明:**

| No | 参数 | 数据类型 | 说明 |
|----|------|----------|------|
| 1 | option | nvarchar(50) | API 标识，此操作固定为 `updateFormulaProcess` |
| 2 | plant | nvarchar(50) | 厂别，可为空 |
| 3 | machineId | int | 设备编号，不可为空 |
| 4 | formulaCode | nvarchar(50) | 配方编号，不可为空 |
| 5 | StepNo | int | 步序，不可为空 |
| 6 | ActionID | int | 动作编号，不可为空；详见下表 |
| 7 | MixingTime | decimal(10,1) | 混炼时间，可为空 |
| 8 | MixingCurrent | decimal(10,1) | 混炼温度，可为空 |
| 9 | MixingTemp | decimal(10,1) | 电流，可为空 |
| 10 | RotateSpeed | decimal(10,1) | 转速，可为空 |
| 11 | Pressure | decimal(10,1) | 压力，可为空 |
| 12 | ClosingConditionID | int | 完成条件，可为 0；详见下表 |
| 13 | TurningTimes | int | 翻转次数，可为空 |
| 14 | RisingTime | decimal(10,1) | 上升时间，可为空 |
| 15 | FallingTime | decimal(10,1) | 下降时间，可为空 |

### 动作编号 (ActionID)

| ActionID | 动作名称 |
|----------|----------|
| 1 | 手工入胶小料 |
| 2 | 入主料 |
| 3 | 塑炼 |
| 4 | 混炼 |
| 5 | 翻料混炼 |
| 6 | 清扫 |
| 7 | 上顶栓上升 |
| 8 | 上顶栓浮动 |
| 9 | 排料 |

### 完成条件 (ClosingConditionID)

| ClosingConditionID | 完成条件名称 |
|--------------------|-------------|
| 1 | 时间 |
| 2 | 温度 |
| 3 | 时间和温度 |
| 4 | 时间或温度 |

### 写入数据示例

```json
{
  "option": "updateFormulaProcess",
  "plant": "",
  "machineId": 1,
  "formulaCode": "F001",
  "formulaName": "配方001",
  "FormulaProcessEntryList": [
    {
      "StepNo": 1,
      "ActionID": 2,
      "MixingTime": 0.0,
      "MixingCurrent": 0.0,
      "MixingTemp": 0.0,
      "RotateSpeed": 0.0,
      "Pressure": 0.0,
      "ClosingConditionID": 0,
      "TurningTimes": 0.0,
      "RisingTime": 0.0,
      "FallingTime": 0.0
    },
    {
      "StepNo": 2,
      "ActionID": 9,
      "MixingTime": 0.0,
      "MixingCurrent": 0.0,
      "MixingTemp": 0.0,
      "RotateSpeed": 0.0,
      "Pressure": 0.0,
      "ClosingConditionID": 0,
      "TurningTimes": 0.0,
      "RisingTime": 0.0,
      "FallingTime": 0.0
    }
  ]
}
```

**写入成功返回结果:**

```json
{ "success": 1, "rtnmsg": "ok" }
```

**写入失败返回结果示例:**

```json
{ "success": 0, "rtnmsg": "Invalid parameter:machineId" }
```

> **注意:** 系统在接收数据时会验证数据格式是否正确，并且最后一步必须为排料（ActionID 为 9）。在新建工单及工单启动时会进行以下验证：工艺步序的合理性（如入料应在其他工艺之前）、是否缺少必要的工艺步序（如缺少入料步序）；不通过验证则弹窗提示用户。

## 6. 小料扫码防错

工单生产中并且该工单中存在小料时扫码，会根据比对结果亮灯：
- 若正确则生成扫码记录
- 当所有料计量完成后，灯灭

---

## 7. 成品包装贴标机

成品包装画面新增贴标机打印按钮，用户可手动选择需要打印的工单，点击一次打印，系统会按照贴标机方提供的协议将该条码数据发送给贴标机。

- **通信方式:** TCP 通信，JSON 格式
- **传输内容:** 与成品包装目前所打印的标签保持一致（工单编号、配方编号、配方重量、有效期）

---

## 补充说明

通过 API 接口进行工单新增时，如果该工单的配方中原料的料桶与现有料桶关系不符，或者工艺不合理、缺失等情况，系统会不予通过新增工单，返回如下错误：

```json
{ "success": 0, "rtnmsg": "Incorrect formulaDetail" }
```
